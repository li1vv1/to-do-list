# To-Do List

Веб-приложение для списка дел: задачи можно добавлять, редактировать, удалять, отмечать выполненными, сортировать, фильтровать, искать и перетаскивать.

Сайт: <https://li1vv1.github.io/to-do-list/>

## Стек

HTML, CSS, JavaScript.

## Структура страницы

В `index.html` находится только базовый каркас и подключение скрипта. Вся страница создаётся динамически из JavaScript с помощью DOM API, с использованием семантических тегов.

## Добавление задачи

Форма состоит из поля названия, поля даты и кнопки «Добавить». Оба поля обязательны. После добавления форма очищается.

## Список задач

Каждая задача содержит:

- галочку «выполнено»: выполненная задача зачёркивается и меняет фон;
- название и дату;
- кнопку «Изменить»: название и дату можно поправить прямо в карточке и сохранить;
- кнопку «Удалить».

## Сортировка, фильтр и поиск

- сортировка по дате: сначала ранние или сначала поздние;
- фильтр по статусу: все, невыполненные, выполненные;
- поиск по названию: список фильтруется во время набора, без учёта регистра.

Фильтр и поиск работают одновременно.

## Перетаскивание

Порядок задач можно менять с помощью drag-and-drop: достаточно перетащить карточку на место другой.

## Сохранение данных

Задачи, их статусы и порядок сохраняются в localStorage браузера и восстанавливаются при загрузке страницы.

## Адаптивность

Макет построен на Flexbox. Сайт корректно отображается на компьютере, планшете и смартфоне.
